### BINDINGS

`Super`&rarr; Win

#### Programs

| Binding     | Program                      |
| ----------- | ---------------------------- |
| `Super + T` | Terminal                     |
| `Super + B` | Browser                      |
| `Super + N` | Editor                       |
| `Super + E` | GUI File Manager             |
| `Super + Y` | Terminal File Manager (yazi) |
| `Super + R` | App Launcher (wofi)          |
| `Super + W` | Wallpaper picker             |

#### General

| Binding             | Action                        |
| ------------------- | ----------------------------- |
| `Super + C`         | Close the active window       |
| `Super + M`         | Open the shutdown menu        |
| `Super + X`         | Lock the screen               |
| `Super + Shift + N` | Toggle the notification panel |

#### Screenshots

| Binding             | Action                    |
| ------------------- | ------------------------- |
| `Super + A`         | Capture a region          |
| `Super + Shift + A` | Capture a window          |
| `Super + Ctrl + A`  | Capture the active output |

#### Window management

| Binding                   | Action                                           |
| ------------------------- | ------------------------------------------------ |
| `Super + H/J/K/L`         | Focus left/down/up/right                         |
| `Super + Shift + H/J/K/L` | Move the active window left/down/up/right        |
| `Super + V`               | Toggle floating mode                             |
| `Super + Shift + V`       | Toggle the split direction in the dwindle layout |
| `Super + P`               | Toggle pseudo-tiling                             |
| `Super + left drag`       | Move a window                                    |
| `Super + right drag`      | Resize a window                                  |

#### Media

| Binding              | Action                          |
| -------------------- | ------------------------------- |
| `Volume Up/Down`     | Raise or lower volume by 5%     |
| `Mute`               | Toggle output mute              |
| `Mic Mute`           | Toggle microphone mute          |
| `Brightness Up/Down` | Raise or lower brightness by 5% |
| `Next/Previous`      | Change media track              |
| `Play/Pause`         | Toggle media playback           |
